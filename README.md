# Digital Signal Encoder and Decoder

**Course:** ITT 036 — Data Communication  
**Assignment:** Programming Assignment 1, Autumn 2026

A Python command-line project for generating digital bitstreams, implementing line coding and scrambling, converting sampled analog values using PCM, plotting waveforms, and decoding line-coded signals from saved waveform images.

## Features

- Generate random binary streams or streams containing four or eight consecutive zeros.
- Find the longest contiguous palindrome using Manacher's algorithm.
- Implement NRZ-L, NRZ-I, Manchester, Differential Manchester, and AMI line coding.
- Apply B8ZS or HDB3 scrambling when AMI is selected.
- Encode and decode sampled analog values using Pulse Code Modulation (PCM).
- Plot digital streams, encoded signals, and reconstructed PCM waveforms.
- Decode line-coded data by analysing the pixels of a waveform image generated by the project.

The image-based decoder is designed for the waveform image format generated by this project.

## Requirements

- Python 3.10 or later
- Dependencies listed in `requirements.txt`

## Setup and Execution

Clone the repository and enter the project directory:

```bash
git clone https://github.com/Akashat-Tiwari/DataCommunication_Project.git
cd DataCommunication_Project
```

Create and activate a virtual environment, then install the dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

Choose digital input for bitstream generation and line coding, or analog input for PCM encoding and reconstruction.

Generated plots are saved in the `outputs/` directory when the application runs without an interactive graphical display.

## Running Tests

Run the complete test suite from the project root:
